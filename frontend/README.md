# Frontend

Статический сайт, без сборки. Модель выполняется полностью в браузере
пользователя (файлы никуда не отправляются).

## Запуск

```bash
cd frontend
python -m http.server 8080
```
Открыть `http://localhost:8080`.

(Открывать `index.html` напрямую двойным кликом нельзя - Worker и
динамические `import()` не работают через `file://`.)

## Структура

```
frontend/
  index.html              # UI: очередь загруженных фото, слайдер до/после, ручная донастройка
  src/
    photoEnhancer.js       # публичный API (см. корневой README, раздел "API")
    enhanceWorker.js        # Web Worker: инференс модели + первичная коррекция
    heicLoader.js           # конвертация HEIC/HEIF -> PNG перед обработкой
  model/                    # сюда кладётся экспортированная модель (см. корневой README)
```
